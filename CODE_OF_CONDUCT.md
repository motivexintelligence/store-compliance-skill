# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work and not the
person, and do not harass anyone in issues, pull requests or any other project space.

## Reporting

Report unacceptable behaviour to **info@motivexintelligence.com**. All reports are
reviewed and kept confidential. Maintainers may remove comments, commits or contributions
that break this code, and may block contributors who do so repeatedly.
